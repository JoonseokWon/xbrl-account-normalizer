# DSD 표를 Excel로 가져오기

DSD·공시 XML의 각 표를 별도 Excel 시트로 가져옵니다. 기존 `DSD·IXD 대사`의 로컬 XML 표 읽기를 재사용하며 인터넷·Excel 프로그램·마우스·키보드 조작이 필요하지 않습니다. XML이 없는 독자적 바이너리 DSD는 지원하지 않습니다.

## 보존하는 정보

- 표의 실제 행·열 위치와 셀 병합을 그대로 배치합니다. 금액을 합산하거나 원·천원·백만원 단위를 변경하지 않습니다.
- 공란, 대시, 0을 구분합니다. 괄호 음수는 음수 숫자, 백분율은 비율 숫자와 `%` 표시 형식으로 저장합니다. 숫자처럼 보이는 머리글과 선행 0 표기는 텍스트로 유지합니다.
- Excel의 15자리 숫자 정밀도를 넘거나 안전하게 표현하지 못하는 값은 원문 텍스트로 보존하고 결과에 건수를 표시합니다. 반올림으로 맞추지 않습니다.
- 수식처럼 보이는 계정명·설명도 OOXML 텍스트로 저장합니다. 수식, 매크로, 외부 링크를 만들지 않습니다.
- `변환안내`에 표별 시트·XML 멤버·원본 표 번호·행과 열 수·기간과 단위 힌트를 표시합니다. 표 밖 문장, 문서의 전체 서식과 태깅 의미는 원본에서 확인해야 합니다.
- `본문`에는 표 밖 XML의 제목·문장·인라인 텍스트·일반 텍스트 노드를 문서 순서대로 보관합니다. 순서·XML 멤버·절제목 경로 요약·원문문구·원본 문단 ID와 XML 행 번호를 함께 표시합니다. 절제목은 표시용 경로 요약이며 제목의 전체 원문은 원문문구에도 별도 보존합니다. 이미지·첨부·시각적 페이지 배치와 표 안 셀 밖 서술은 변환하지 않습니다.

기존 표 시트의 셀 값을 편집한 뒤 `Excel→DSD` 작업에서 이 Excel과 원본 DSD를 함께 선택하여 반영합니다. `변환안내`와 `본문`은 참고용이며 이 시트들의 편집은 DSD에 자동 반영하지 않습니다. 행·열·표 추가/삭제, 셀 병합 변경, 전기 금액을 당기로 이동하는 판단도 자동으로 반영하지 않습니다. 새 결과 파일은 원본에 덮어쓰지 않습니다.

## 대응 정보와 검증

`_DSD_META`, `_DSD_CELLS`는 숨긴 대응 시트입니다. 원본 SHA-256·파일명·전체 셀 수와 원본 셀 ID, XML 멤버·표·행·열·병합, Excel 시트·셀 주소, 원문 값과 정확한 숫자 문자열을 보관합니다. 전체 원문 XML은 Excel에 포함하지 않습니다.

숨긴 시트는 전자서명이나 접근 통제가 아닙니다. Excel→DSD 작업에서는 사용자가 별도로 선택한 원본 DSD로 대응 정보를 다시 만들고 **전체 대응을 비교한 뒤** 편집 값을 사용해야 합니다. 파일명을 바꾸거나 숨긴 정보를 고쳐 다른 원본에 적용할 수 없습니다.

읽기 전후와 출력 저장 전 원본 해시를 확인합니다. 새 Excel은 임시 파일에서 완성·패키지 안전 검사를 마친 뒤 기존 파일을 교체하지 않는 방식으로 저장합니다. 저장 실패·원본 변경 시 불완전한 결과를 남기지 않습니다.

Excel 내보내기 한도는 원본 셀 100,000개, 표 256개, 표별 80열·100,000행, 전체 병합 범위 포함 1,000,000셀, 셀별 32,767 UTF-16 코드 단위입니다. Excel 출력은 기존 안전 XLSX 입력 한도를 적용합니다. 초과 시 표나 텍스트를 자르지 않고 전체 작업을 거절합니다.

본문 읽기는 공용 문서 읽기 모듈의 문단 10,000개·전체 텍스트 16Mi문자와 기존 ZIP/XML 한도를 적용합니다. 본문 원문이나 절제목 경로가 Excel 셀 한도를 넘으면 텍스트를 자르지 않고 전체 내보내기를 중단합니다. 지원 범위는 읽을 수 있는 XML 표가 있는 DSD/공시 원문입니다.

## API

```python
from xbrl_filing.dsd_excel import export_dsd_excel

report = export_dsd_excel('원본.dsd', '주석표.xlsx')
print(report['counts'], report['warnings'])
```

반환 객체는 JSON으로 저장할 수 있으며 원본과 결과 해시, 표별 대응, 정밀도 때문에 텍스트로 보존한 건수와 예시를 포함합니다. 공식 작성기 생성·공식 검사 통과·DART 접수 여부는 항상 별도로 표시합니다.
