# 벤토 그리드 UI 설계

참고: https://developers-apps-in-toss.toss.im/design/consumer-ux-guide

가이드의 UX 원칙을 Windows 데스크톱 환경에 맞춰 적용했습니다.

| 원칙 | 화면에 반영한 방식 |
|---|---|
| 행동을 예상할 수 있는 버튼 | 엑셀 파일 선택, 계정 후보 불러오기, 이 계정으로 연결, 검토 엑셀 저장 |
| 해요체·능동형 문구 | 자료를 연결해요, 파일을 읽었어요, 새 폴더에 저장했어요 |
| 예측 가능한 이동 | 자료 준비 → 열 연결 → 계정 검토 → 변환 결과, 왼쪽에서 앞 단계로 이동 |
| 필요한 정보 우선 | 자료 카드와 작업 정보는 크게, 연결 예시와 요약은 보조 카드로 배치 |
| 상태를 정확하게 표시 | 실제 처리 중에만 진행 표시, 미확정·오류를 별도 수치와 텍스트로 표현 |
| 불필요한 방해 최소화 | 시작 광고·동의 팝업 없이 바로 자료 선택. 저장하지 않은 변경을 버릴 때만 확인 |
| 정돈된 그래픽 | 자체 벡터 아이콘, 제한된 파란 강조색, 흰 카드와 충분한 간격 |
| 다양한 화면 크기 대응 | Qt 논리 좌표·DPI 처리, 스크롤 가능한 본문, 고정 상단 작업 버튼 |

UI는 밝은 화면을 기준으로 작성했고 OFL 글꼴 Noto Sans KR을 포함합니다. 토스 고유 그래픽·로고·폰트는 포함하지 않습니다. 앱인토스 입점·검수 인증을 주장하지 않습니다.

## 확인한 범위

초기 화면을 오프스크린 렌더링하여 한글 글꼴과 카드·버튼 배치를 살펴봤습니다. 변환, 계정 검토 이벤트, 결과 파일, 여러 화면 크기의 실사용 검증은 사용자가 확인할 수 있도록 남겼습니다.
