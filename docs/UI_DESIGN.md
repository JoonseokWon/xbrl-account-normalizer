# 벤토 그리드 UI 설계

참고: https://developers-apps-in-toss.toss.im/design/consumer-ux-guide

가이드의 UX 원칙을 Windows 데스크톱 환경에 맞춰 적용했습니다.

| 원칙 | 화면에 반영한 방식 |
|---|---|
| 행동을 예상할 수 있는 버튼 | 새 파일 열기, 열 연결 설정, 계정 후보 불러오기, 이 계정으로 연결, 검토 엑셀 저장 |
| 해요체·능동형 문구 | 자료를 연결해요, 파일을 읽었어요, 새 폴더에 저장했어요 |
| 예측 가능한 이동 | 자료 준비 → 열 연결 → 계정 검토 → 변환 결과, 왼쪽에서 앞 단계로 이동 |
| 필요한 정보 우선 | 자료 카드와 작업 정보는 크게, 연결 예시와 요약은 보조 카드로 배치 |
| 상태를 정확하게 표시 | 실제 처리 중에만 진행 표시, 미확정·오류를 별도 수치와 텍스트로 표현 |
| 불필요한 방해 최소화 | 시작 광고·동의 팝업 없이 바로 자료 선택. 저장하지 않은 변경을 버릴 때만 확인 |
| 정돈된 그래픽 | 자체 벡터 아이콘, 제한된 파란 강조색, 흰 카드와 충분한 간격 |
| 다양한 화면 크기 대응 | Qt 논리 좌표·DPI 처리, 스크롤 가능한 본문, 고정 상단 작업 버튼 |

UI는 밝은 화면을 기준으로 작성합니다. v0.3.1부터 Windows에서 설치된 맑은 고딕을 우선 선택하고, 한글 글꼴을 사용할 수 없는 환경에는 포함된 OFL 글꼴 Noto Sans KR을 사용합니다. Windows 글꼴 파일은 재배포하지 않습니다. 토스 고유 그래픽·로고·폰트는 포함하지 않습니다. 앱인토스 입점·검수 인증을 주장하지 않습니다.

v0.3.2는 첫 화면의 합성 예제 버튼을 제거하고 `새 파일 열기 → 회사 정보 → 열 연결 설정`을 기본 흐름으로 사용합니다. 특정 회사 목록을 내장하지 않습니다. 새 파일을 읽는 데 성공한 뒤 이전 작업을 초기화하며 취소·읽기 실패 시에는 기존 작업을 유지합니다.

v0.4는 변환 결과 화면에 `통합감사 입력 저장`을 추가했습니다. 변환 오류·미확정이 없는 원장에서 활성화하고, 별도 시산표·통제 보조파일과 저장 위치를 선택합니다. 합성자료는 사용자 파일처럼 직접 여는 예제로 제공하며 특정 회사를 UI에 고정하지 않습니다.

본문은 13px에서 11pt(기준 DPI에서 약 15px), 안내 글자는 12px에서 10.5pt(약 14px)로 키웠습니다. 제목의 음수 자간을 제거하고 안내·탭·표 헤더 색을 진하게 조정했습니다. 글꼴 설정은 `desktop/theme/typography.py`, 크기는 `desktop/theme/tokens.py`에 모았습니다.

Qt의 Windows 모니터별 DPI 처리를 유지하며 글꼴에는 Full Hinting을 요청합니다. 미리보기는 Windows에서 실제 글꼴 엔진으로 숨김 렌더링합니다. 참고: https://doc.qt.io/qt-6/highdpi.html 및 https://doc.qt.io/qt-6/qfont.html#HintingPreference-enum

## 확인한 범위

100·125·150·200% 배율에서 데이터가 없는 다섯 화면을 렌더링해 글꼴과 배치를 살펴봤습니다. 150%에서는 최소 창 크기 1070×740도 확인했습니다. 변환, 계정 검토 이벤트, 결과 파일, 모니터 간 이동 등 실사용 검증은 사용자가 확인할 수 있도록 남겼습니다.
