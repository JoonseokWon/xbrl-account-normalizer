# 주석 표 문맥과 대응 후보·차이 확인

상단 **공시 검토 → DSD·IXD 숫자 대사**에서 사용할 수 있습니다.

1. XML 표를 포함한 DSD와 준비한 IXD를 선택하고 **셀·공시 항목 읽기**를 누릅니다.
2. 선택 사항으로 **택사노미 이름 읽기**에서 이용 권한이 있는 로컬 공식 XSD 진입점을 선택합니다. 기존 로컬 DTS 읽기 서비스를 사용하며 인터넷에서 파일을 내려받지 않습니다. 한글 이름은 namespace와 localName이 같은 실제 IXD 개념에만 연결합니다.
3. DSD 숫자 셀을 선택합니다. `2025년 / 기말` 같은 전체 열 머리글과 `무형자산 / 개발비` 같은 행 문맥, 원문 단위 안내를 확인합니다. 표의 표시 단위를 원·천원·백만원 중 직접 선택합니다.
4. **대응 후보 3개 → 선택한 셀의 후보 찾기**를 누릅니다. 이름 유사도·열의 명시적 연도·선택한 배율의 금액 일치·명시적 통화 단위를 근거로 기존 IXD에서 최대 3개를 찾습니다. 가까운 본문의 여러 연도로 당기·전기를 추정하지 않으며 차원을 자동 승인하지 않습니다.
5. 후보의 근거·주의사항을 보고 **이 후보 선택**을 누릅니다. 다른 팩트를 원하면 **전체 항목**에서 직접 검색합니다. 후보 선택만으로 대응표는 바뀌지 않습니다.
6. 아래 회사 식별자·전체 기간·개념·단위·차원·언어를 원문과 비교합니다. 확인 체크 후 **선택한 대응 확인**을 눌러야 대응표에 반영됩니다.
7. **대사 실행** 후 **차이·미대응만**, **부호 확인**, **표시 단위 확인**, **단수 차이 가능성** 필터로 항목을 좁힙니다. 행을 선택하면 원본 위치와 확인할 원인이 보입니다. JSON·CSV에는 필터에 관계없이 전체 결과를 저장합니다.

## 후보의 의미

이 기능은 기존 IXD와의 대응을 돕는 규칙 기반 검색입니다. 원장 계정 검토의 로컬 Ollama LLM 추천과 구분됩니다. 새 IFRS/DART 개념을 만들거나 DSD를 XBRL로 자동 태깅하지 않습니다. 점수는 정답 확률이 아니며, 같은 금액만 근거인 후보·통화나 연도가 다른 후보·동일 문맥 중복은 주의사항을 표시합니다. 0~3개를 제시하고 빈자리를 관련 없는 후보로 채우지 않습니다.

병합된 열·행 머리글은 XML의 실제 셀 위치로 읽습니다. 텍스트 기반 표나 특수 서식의 의미를 모두 복원하는 기능은 아닙니다. 검토 문맥은 행·열별 최근 32개 머리글, 개별 2,000자와 화면용 결합 경로 600자로 제한하며 원문 셀 값과 위치는 보존합니다. 같은 머리글 문맥은 메모리에서 공유해 큰 표의 반복 복사를 줄입니다. 기존 대응표의 원본 해시와 대사 시 재검사도 유지합니다.

## 차이 원인 힌트

- **부호 확인:** 환산 금액의 절댓값은 같고 부호가 반대입니다. 차변·대변과 손익 표시 기준을 확인합니다.
- **표시 단위 확인:** 현재 배율에서는 다르지만 원·천원·백만원 중 다른 배율로 바꾸면 같습니다. 자동 변경하지 않습니다.
- **단수 차이 가능성:** 차이가 DSD 마지막 표시 자리의 절반 이내입니다. 예를 들어 `1,234천원`과 `1,234,499원`은 차이 `-499원`을 유지하며 단수 차이 가능성만 표시합니다. 이 범위는 XBRL `decimals` 검증이나 공시 허용 오차가 아닙니다.

모든 비교는 Decimal로 계산하고 비영 차이는 계속 **금액 차이**입니다. 부호 변경·반올림·0 채우기·금액 합산을 자동 수행하지 않습니다. 회사별 주석 완전성, 회계 적정성, 공식 작성기 검사와 DART 접수는 별도로 확인합니다.

설계 근거는 [인벡터 공개 소개서](https://featpaper.com/l/RF8eenm6), [XBRL 2.1과 정확도·단위 안내](https://specifications.xbrl.org/work-product-index-group-base-spec-base-spec.html), [OpenDART 공시 원문 ZIP/XML 안내](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)입니다. 외부 프로그램·비공개 자료를 사용하지 않았습니다.
