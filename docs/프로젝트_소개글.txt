회계데이터 표준화 | 엑셀 계정 연결·XBRL·공시 검토 Windows 앱

회사마다 다르게 표현한 엑셀 계정을 공통 코드로 연결하고, 감사 입력과 XBRL XML을 준비하는 Windows 앱입니다. 공시문서와 IXD의 숫자를 비교하고 주석·수정 이력을 관리하며 다음 연도 업무를 이어서 사용할 수 있습니다.

• 새 파일 열기로 회사별 엑셀을 선택하고 시트·열을 표준 항목에 연결
• 회사·ERP별 입력 설정 재사용, CSV·여러 파일 입력, 업무 저장·다시 열기
• 표준 계정 사전 관리, 전표별 복합분개·시산표 대사·원본 행 확인
• 계정명·별칭 기반 표준 계정 후보와 추천 근거 확인
• 사용자 확인·거절 이력 저장 및 다음 작업에 재사용
• 10개 더미 회사·624개 계정 표현 연결, 명확한 별칭 322개 누적
• 검토 엑셀·JSON 저장과 통합감사 원장·리드용 7시트 입력 변환
• 공식 XBRL GL XML 저장, 오프라인 스키마·원본 보존 확인과 Arelle 검증 예제
• 저장한 XML 결과 폴더 재검사와 오류·행수·금액을 읽는 한국어 HTML 보고서
• 100행씩 출력 행 검토, 은행·계좌 등 연결 정보와 같은 원본 업무의 행으로 이동
• XML 저장·내용 확인 진행률 표시와 현재 업무를 보존하는 저장 취소
• 공시 XLSX·CSV·JSON 입력, 빈 엑셀 양식과 별도 .acfiling 공시 업무
• BS·PL·CF·CE·주석 팩트의 공식 개념·비교기간·단위·정확도·명시적 차원 검토와 승인
• 공식 로컬 XSD를 이용한 XBRL 2.1 출력과 실행팩 내 Arelle 2.47.3 기술 검사
• DART 공식 엑셀의 역할·개념 검색과 승인 대사표·한국어 보고서 저장
• 토스 UX 가이드를 참고한 벤토 그리드 UI와 Windows EXE

• DSD·IXD 숫자 대사와 회사·기간·단위·차원을 확인한 대응표
• 주석·공시 항목 편집, 변경 전후 조회·복원, 다음 연도 구조 재사용

상태: 공개 저장소 / v0.12.0-preview.1 / 합성자료·소스·EXE 검증
공시 XML: 이용 권한이 있는 공식 XSD와 전체 택사노미를 로컬에서 선택합니다. 원장 순증감으로 기말잔액·현금흐름을 추정하지 않습니다.
DART 엑셀: 개념 메타데이터를 참고한 대사표이며 XML을 생성하지 않습니다. 실제 DART 접수는 수행하지 않습니다.
검사 범위: Arelle의 실제 DTS·자료형·기간·차원과 가능한 계산 관계를 확인합니다. 필수 공시·주석 완전성·회계 적정성·DART 수리를 보장하지 않습니다.
최종 제출: 공식 작성기 본체에서 합성 IXD 생성은 별도로 검증했으며 해당 자동 생성 연결은 이번 EXE에 포함하지 않았습니다. 공식 작성기에서 준비한 IXD를 선택해 대사합니다.
매핑 방식: 사전·별칭·문자열 유사도·승인 이력이며 로컬 LLM이나 외부 LLM API를 사용하지 않습니다.
원본 IFRS/DART 택사노미는 재배포하지 않습니다. 버전별 검사 기록은 릴리스의 validation-summary.json을 참고하세요.
