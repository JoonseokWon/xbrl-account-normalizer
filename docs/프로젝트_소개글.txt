회계데이터 표준화 | 엑셀 계정 연결·XBRL GL 변환 Windows 앱

엑셀 원장과 재무상태표의 계정을 공통 코드에 연결하고, 감사 자동화용 데이터와 공식 XBRL GL XML을 만드는 Windows 앱입니다. 저장 결과를 다시 검사하고 한국어 HTML 보고서와 원본 연결을 확인할 수 있습니다.

• 새 파일 열기로 회사별 엑셀을 선택하고 시트·열을 표준 항목에 연결
• 회사·ERP별 입력 설정 재사용, CSV·여러 파일 입력, 업무 저장·다시 열기
• 표준 계정 사전 관리, 전표별 복합분개·시산표 대사·원본 행 확인
• 계정명·별칭 기반 표준 계정 후보와 추천 근거 확인
• 사용자 확인·거절 이력 저장 및 다음 작업에 재사용
• 10개 더미 회사·624개 계정 표현 연결, 명확한 별칭 322개 누적
• 검토 엑셀·JSON 저장과 통합감사 원장·리드용 7시트 입력 변환
• 공식 XBRL GL XML 저장, 오프라인 스키마·원본 보존 확인과 Arelle 검증 예제
• 저장한 XML 결과 폴더 재검사와 오류·행수·금액을 읽는 한국어 HTML 보고서
• 100행씩 출력 행 검토, 은행·계좌 등 연결 정보와 같은 원본 업무의 행으로 이동
• XML 저장·내용 확인 진행률 표시와 현재 업무를 보존하는 저장 취소
• 토스 UX 가이드를 참고한 벤토 그리드 UI와 Windows EXE

상태: 공개 저장소 / v0.8.0-preview.1 / 회사별 매핑·XBRL GL 출력·저장 결과 재검사 지원
현재 범위: 원장·재무상태표(BS)의 GL 표준화. IFRS/DART 공시용 개념 매핑·제출 형식은 제외합니다.
검사 범위: 앱은 공식 XSD와 파일·행 연결의 내부 일치를 확인합니다. Arelle는 예제의 별도 검사에 사용하며 EXE에 포함하지 않습니다.
