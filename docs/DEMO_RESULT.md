## v0.4 원장 변환 기록

2026-10-25, 노바부품(NOVA_DEMO)의 시험자료를 만들어 실행했습니다. v0.4.1에서는 첫 시트에 전표별 차변·대변 계정과 금액을 나란히 표시하는 분개장을 추가하고, 적요의 접두어를 제거했습니다. 계좌 이체는 차변 신한은행 / 대변 국민은행, 원가 처리는 차변 매출원가 / 대변 재고자산으로 표시합니다. 변환에는 GL_Data만 사용하며 금액·전표·계정코드는 유지합니다.

| 확인 항목 | 결과 |
|---|---|
| 원본 | 영문 열·앞자리 0 코드를 가진 14개 전표, 28개 행 |
| 원본 계정 → 표준 계정 | 8개 → 7개, 은행 계정 두 개를 A1102로 연결 |

계정 연결은 합성 시나리오에 명시한 8개 설정을 적용했습니다. 실제 사람의 승인이나 실제 독립 추출 통제를 만든 기록이 아닙니다. 원장·리드 모듈의 형식 호환성과 기계적 수치 대사·저장만 확인했습니다. 다른 모듈 실행·실제 감사 수행·감사의견·공식 XBRL 적합성을 확인한 결과가 아닙니다. GUI의 실제 OS 파일선택창 조작 검증과도 구분합니다.

소스 GUI의 통합감사 입력 저장 버튼과 백그라운드 저장 완료는 v0.4.0에서 더미 세션으로 확인했습니다. 파일·폴더 선택창은 시험 경로로 대체했으며 실제 OS 파일선택창 조작은 확인하지 않았습니다. v0.4.1은 예제·재현 도구의 표기 변경으로, 변환·감사 입력·업무 재열기를 다시 확인했습니다.
