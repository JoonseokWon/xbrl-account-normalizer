# 회사별 반복 업무

## 새 업무와 입력 설정

1. 새 파일 열기로 같은 회사·양식의 원장을 선택합니다. XLSX 또는 CSV·TSV 파일을 최대 24개 선택할 수 있습니다.
2. 회사코드·ERP·확인자, 필요한 시작일·기준일과 금액 단위를 입력합니다. 원본 회사 열과 업무 회사는 같아야 합니다.
3. 시트·제목 행과 필수 열을 지정합니다. CSV 시트명은 CSV이며 원장/재무상태표 중 한 종류만 선택합니다.
4. 은행·계좌번호·거래처·부서·프로젝트·증빙번호는 필요한 열만 연결합니다.
5. 입력 설정 저장은 회사·ERP별로 저장합니다. 새 파일에서는 같은 회사·ERP를 입력하고 입력 설정 불러오기를 사용합니다. 기간과 보조자료 파일 경로는 다시 지정합니다.

여러 XLSX 파일은 선택한 시트와 열 구조가 같아야 합니다. 다른 양식이나 회사는 별도 업무로 처리합니다. 동일 파일 중복은 거절하고 전표행 중복은 오류로 남깁니다. 기간마다 전표번호가 반복되는 자료는 ERP에서 고유한 전표 ID를 제공해야 합니다. 앱이 임의 접두어로 바꾸지 않습니다.

## 전표와 대사

전표별 분개는 한 전표의 여러 차변·대변을 각각 보여줍니다. 상대 행을 일대일로 추정하지 않습니다. 원본 계정명·코드를 유지하므로 은행 두 개가 같은 표준 계정에 연결돼도 구분할 수 있습니다.

변환·시산표 대사는 원장 행 수와 차대 합계를 비교합니다. 원본 금액이 잘못되면 계산 불가로 표시합니다. 시산표 연결 후 원본 계정별 당기 차대도 비교합니다. 행을 두 번 눌러 원본 열·값을 확인합니다. 원본 수정은 별도 사본에서 진행하고 다시 불러옵니다.

## 업무 저장과 사전 관리

업무 메뉴에서 .acwork 파일에 원본·열 설정·사전·검토 상태를 저장합니다. 새 보조자료 연결을 사용했다면 보조 원본과 설정도 포함합니다. 기존 완성형 보조파일을 내보내기에서 직접 선택한 경우는 업무에 추가하지 않습니다. 다시 열 때 보관 원본의 해시를 확인하고 재계산합니다. 외부 원본 파일을 옮겨도 업무를 열 수 있습니다.

업무 파일에는 원장 내용이 포함됩니다. 사용자 업무·이력·사전·캐시는 공개 릴리스에 포함하지 않습니다. 소스는 user_data/, EXE는 %LOCALAPPDATA%/AccountDataNormalizer에 설정·작업 캐시를 보관합니다.

표준 계정 사전에서는 상세계정/그룹, 상위코드, BS/PL, 리드와 별칭을 관리합니다. 중복·순환·다른 구분의 상위 그룹은 거절합니다. 변경된 사전은 새 버전으로 보관하며 현재 연결을 재확인합니다. 다른 사전 버전의 승인 이력은 재사용하지 않습니다. 저장한 업무를 열면 그 업무에 보관한 사전을 사용합니다.

## 대용량

- 파일당 50MB·100,000행·80열, 업무당 24개 파일·250MB·250,000행
- 10,000행 초과 검토 엑셀은 순차 저장하며 Excel 매핑표 드롭다운 생략
- 통합감사 v2.1 입력은 시트당 10,000행. 초과하면 내보내기 중단
- 큰 엑셀 저장은 배경에서 처리하며 시간이 걸릴 수 있음
- ISO 일자와 확정 KRW 값 사용. 음수 차대는 기존과 같이 별도 원본 규칙 필요
