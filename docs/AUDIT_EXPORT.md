# 통합감사 원장 입력 내보내기

계정 연결을 확인한 KRW 원장을 통합감사프로그램의 `원장·리드` 모듈에 등록할 수 있는 7개 시트의 `.xlsx`로 저장합니다. 통합감사 소스 v2.1.0 계약에 대해 시험했습니다. 다른 모듈의 증빙·실제 수행·감사결론을 완성하는 기능은 아닙니다.

## 사용하는 순서

1. 새 파일 열기로 원본 원장을 열고 회사·원천시스템·시트·열을 연결합니다.
2. 계정 연결을 확인해 변환 오류와 미확정 행을 해결합니다.
3. 변환 결과에서 `통합감사 입력 저장`을 누릅니다.
4. 별도 시산표·통제 보조파일과 저장 위치를 선택합니다.
5. 생성된 `통합감사_원장입력.xlsx`를 통합감사프로그램에서 해당 회사 업무의 `원장·리드` 입력으로 등록합니다. 옆의 `변환출처.json`에는 원장·보조파일 해시와 사용 매핑을 남깁니다.

기존 검토 엑셀 저장은 승인·거절 이력 보관에 사용합니다. 통합감사 입력 저장은 별도 파일을 만들며 기존 원본·통제를 덮어쓰지 않습니다.

## 보조파일 규격

아래 5개 시트를 정확한 열 이름·순서로 준비합니다. `samples/새회사변환예제/02_노바부품_시산표_통제자료.xlsx`의 구조를 참고할 수 있습니다. 실제 자료에서는 실제 회사의 시산표와 별도 추출 통제를 준비해야 합니다.

| 시트 | 열 순서 |
|---|---|
| 설정 | 항목, 값 |
| 시산표 | 회사코드, 계정코드, 계정명, 기초잔액, 당기차변, 당기대변, 기말잔액 |
| 독립통제 | 회사코드, 시작일, 기준일, 계정코드, 원장행수, 차변합계, 대변합계, 기초잔액, 기말잔액, 추출근거, 추출일시, 작성자 |
| 감사조정 | 조정ID, 행ID, 계정코드, 차변, 대변, 근거, 상태 |
| 모듈연결 | 모듈, 지표, 계정코드, 비교기준, 부호 |

설정에는 회사코드·시작일·기준일·통화(KRW)·추출범위가 필요합니다. 추출범위는 원본 계정코드를 `;`로 구분한 목록입니다. 숫자처럼 보이는 코드는 텍스트로 보존하고, 기초·기말잔액은 차변 양수·대변 음수로 입력합니다. 차변·대변은 각각 0 이상의 원 단위 정수입니다. 보조파일은 확정값만 사용합니다.

독립통제는 원장으로 새로 계산해서 채우지 않습니다. 제공받은 행 수·총차변·총대변·기초·기말을 변환 결과와 비교하며 다르면 내보내기를 중단합니다. 일치해도 통제의 실제 독립성·진위나 감사 적정성을 인증하지 않습니다. 추출일시는 기준일 이후의 시간대 포함 문자열입니다. Excel의 날짜 자동 변환을 막으려면 `'2026-02-02T09:00:00+09:00`처럼 텍스트로 입력합니다.

감사조정이 없거나 모듈 연결을 아직 지정하지 않았다면 해당 시트는 헤더만 둡니다. 승인 조정을 자동 생성하지 않습니다. 원장에 당기 거래가 없는 시산표 계정은 선택적인 `계정매핑` 시트(계정코드, 리드코드, 리드명, 표시구분)로 명시합니다. 이미 확인한 원장 매핑과 충돌하면 중단합니다.

원본 계정코드를 유지하며 한 회사씩 내보냅니다. 모든 시트는 10,000개 데이터 행 이내입니다. `총계정원장`과 `계정매핑`은 확인한 표준화 결과에서 가져오고, 나머지 5개 시트는 보조파일 값을 사용합니다. 원장 당기변동을 기말잔액으로 대체하지 않습니다.
