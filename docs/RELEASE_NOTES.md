- 큰 7시트 감사 입력을 순차 저장해 메모리 사용 감소, 코드·전표·행·출처 보존
- 보조표 10,000행 제한과 독립 통제·기간·중복·차대변 검사 유지
- 통합감사 v2.3.0 이상 사용 필요. 이전 감사 EXE에는 기존 제한이 남음
- 표준화 원본 한도는 파일당 100,000행, 업무당 250,000행으로 유지

## v0.5.0-preview.1 — 회사별 입력·분개·대사·업무 저장

- 회사·ERP별 열 연결 설정 저장/불러오기. 기간·보조자료 경로는 다음 업무에서 다시 지정
- 표준 계정 사전 추가·수정, 중복·상위 그룹·순환 검사, 사전 변경 시 연결 재확인
- 전표별 여러 차변·대변 표시와 원본 행 확인. 은행·계좌·거래처·부서·프로젝트·증빙번호 보존
- 원본/변환 행 수·차대 합계와 계정별 시산표 대사. 계산 불가·차이·누락 표시
- 회사 양식의 시산표·통제·감사조정·모듈연결 열 연결. 제공 통제의 금액·행 수는 원본 열에서만 사용
- .acwork 업무에 원본·보조 원본·사전·열 설정·검토 상태 보관, 해시 확인 후 복원
- XLSX·UTF-8/CP949 CSV·TSV, 최대 24파일·250,000행. 큰 검토 엑셀 순차 저장
- 단위 테스트 58개, 소스 Qt 버튼·배경 작업·업무 복원, 100,004행 처리·엑셀 저장 확인
- 통합감사 v2.1.0 복합분개 27/27, 노바 원장 67/67 대사 일치·차단 0건 확인

Windows ZIP을 모두 풀고 AccountDataNormalizer.exe를 실행하세요. _internal 폴더를 함께 보관합니다. 새 기능은 상단 업무 메뉴와 변환 결과 화면에서 사용할 수 있습니다. 회사별 사용법은 docs/COMPANY_WORKFLOW.md입니다.

원본은 파일당 50MB·100,000행이며 전체 업무는 250MB·250,000행 이내입니다. 통합감사 v2.1 입력 계약은 여전히 시트당 10,000행으로 초과 내보내기를 차단합니다. 큰 검토 엑셀 저장은 이 PC에서 약 69초 걸렸으며 환경에 따라 다릅니다. 업무 저장은 검토 상태 보관이며 사람의 승인·감사결론을 생성하지 않습니다. 테스트는 합성자료와 소스 GUI를 사용했고 OS 파일선택창은 시험 경로로 대체했습니다. 공식 XBRL 출력은 지원하지 않습니다.

## v0.4.0-preview.1 — 새 회사 원장 변환·통합감사 원장 입력

- 계정 연결을 확인한 원장과 별도 시산표·통제 보조파일을 7시트 통합감사 입력 엑셀로 변환
- 회사·기간·계정 범위·통제 금액·시산표 변동을 비교하고 불일치·미확정·충돌 매핑은 차단
- 원본 계정코드와 행ID, 원장·보조파일 해시와 사용 매핑을 보존
- 원장 당기변동으로 기말잔액·독립통제를 만들어 채우지 않음
- 노바부품의 14개 전표·28개 행 예제와 명시 시험 매핑 제공
- 통합감사 소스 v2.1.0의 새 더미 업무에 실제 등록·실행·저장·재열기, 대사 67개 일치·차단 0건
- 단위 테스트 35개 통과. 주말 전표 2개 행은 검토후보로 유지

Windows ZIP을 모두 풀고 AccountDataNormalizer.exe를 실행하세요. _internal 폴더를 함께 보관합니다. 계정 연결을 마친 뒤 변환 결과의 통합감사 입력 저장을 사용합니다. 보조파일 규격은 docs/AUDIT_EXPORT.md, 예제는 samples/새회사변환예제에 있습니다.

확인 범위는 합성 원장·리드 입력의 형식·수치·저장입니다. 통제·매핑은 시험 설정이며 실제 독립 추출 증거·실제 사람의 승인·감사결론이 아닙니다. 모든 GUI/모듈·다른 PC·실사용 자료·공식 XBRL 적합성을 검증한 결과로 읽지 않습니다. 업무 DB·개인 자료는 공개 배포에 포함하지 않습니다.
