# v0.9.0-preview.1 — IFRS 공시 XML·DART 개념 연결과 대사표

- 확정 재무상태표·손익·현금흐름·자본변동·주석 입력, 당기·비교기간 최대 3개와 명시적 차원 지원
- 회사별 공시 엑셀 빈 양식·CSV·JSON, 현재 업무의 BS 가져오기, 별도 .acfiling 검토 업무 저장·열기
- 공식 로컬 XSD 진입점의 실제 DTS로 개념·기간·자료형을 읽고 사용자 승인 후 XBRL 2.1 XML 출력
- Arelle 2.47.3을 EXE에 포함해 오프라인 자료형·기간·단위·차원·적용 가능한 Calculations 1.0/1.1 검사
- 금액 배율과 decimals 정확도 구분, 원본 코드·앞자리 0·출처·승인 근거 보존, 중복 팩트 자동 합산 차단
- 원본·택사노미 해시 재확인, 미확정·변경 원본·합계 오류 차단, 완료 전 임시 결과 원자적 처리
- DART 공식 엑셀의 한국어 개념·업종·연결/별도 서식별 검색과 승인 입력 대사표. 이 경로는 XML 생성 없이 메타데이터만 검사
- IFRS/DART 택사노미 원본은 제품·소스에 재배포하지 않고 사용자가 이용 권한이 있는 공식 파일을 로컬에서 선택
- 실제 DART DTS·DART 편집기 불러오기·공시 접수는 이번 릴리스에서 검증하지 못함. 접수용 최종 파일 생성·검사는 금융감독원 공식 작성기에서 수행
- 검사 실적과 제외 범위는 validation-summary.json 및 docs/IFRS_DART.md 참고
