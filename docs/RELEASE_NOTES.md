# v0.3.2-preview.1 — 새 파일 열기로 회사별 엑셀 작업 시작

첫 화면에서 실제 사용할 엑셀 파일을 바로 선택하도록 작업 시작 흐름을 정리했습니다.

- 첫 화면의 합성 예제 버튼 제거
- 새 파일 열기로 회사별 원장·재무상태표 .xlsx 선택
- 파일을 연 뒤 회사 정보 확인, 열 연결 설정, 계정 검토 순서로 진행
- 작업 중에도 상단 새 파일 열기로 다른 파일 선택
- 새 파일 읽기 성공 시 이전 회사 정보·열 연결·검토 목록·결과 초기화
- 파일 선택 취소 또는 시트 정보 읽기 실패 시 현재 작업 유지
- 저장하지 않은 계정 연결을 바꾸기 전 확인 안내

## 다운로드와 시작

account-data-normalizer-0.3.2-preview.1-windows-x64.zip을 모두 풀고 AccountDataNormalizer.exe를 실행하세요. _internal 폴더를 함께 보관해야 합니다. Python·Codex 설치가 필요하지 않습니다.

## 확인 범위

빈 화면 렌더링과 EXE 시작·내장 리소스 로딩은 배포 준비로 확인합니다. 사용자 요청에 따라 업무 변환·회계 결과·GUI 업무 흐름의 실행 검증은 사용자가 수행하도록 남깁니다. 사용자 검증 대기 상태의 prerelease입니다.

입력은 지원 필드가 있는 확정값 .xlsx이며 재무제표 범위는 BS입니다. 원장에 계정명이 없는 경우에는 계정명을 포함한 입력 사본을 준비해야 합니다. 공식 XBRL GL 출력과 기존 감사 앱 직접 불러오기는 향후 확장 항목입니다.
