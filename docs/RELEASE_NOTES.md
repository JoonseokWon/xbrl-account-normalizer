# v0.3.1-preview.1 — Windows 한글 가독성 수정

작고 옅은 한글 안내가 흐려 보이는 문제를 줄이도록 글꼴과 글자 크기·대비를 조정했습니다.

- Windows에 설치된 맑은 고딕을 우선 사용하고, 사용할 수 없으면 포함된 Noto Sans KR로 대체
- 본문 11pt, 안내 10.5pt로 확대하고 제목의 음수 자간 제거
- 안내·탭·표 헤더·입력 안내의 글자색을 진하게 조정
- 사이드바·버튼·배지·표 행의 공간을 큰 글자에 맞춰 조정
- Windows의 모니터별 DPI 처리를 유지하고 실제 Windows 글꼴 엔진으로 미리보기 생성

## 다운로드와 시작

`account-data-normalizer-0.3.1-preview.1-windows-x64.zip`을 모두 풀고 `AccountDataNormalizer.exe`를 실행하세요. `_internal` 폴더를 함께 보관해야 합니다. Python·Codex 설치가 필요하지 않습니다.

## 확인 범위

100·125·150·200% 배율에서 데이터가 없는 다섯 화면의 글꼴·배치를 렌더링했습니다. 150%에서는 1070×740 창도 확인했습니다. EXE 시작·내장 리소스 로딩은 배포 준비로 확인합니다.

사용자 요청에 따라 업무 변환·회계 결과·GUI 업무 흐름의 기능 검증은 실행하지 않았습니다. 사용자 검증 대기 상태의 prerelease입니다. 현재 재무제표 범위는 BS이며 공식 XBRL GL 출력과 기존 감사 앱 직접 불러오기는 향후 확장 항목입니다.
