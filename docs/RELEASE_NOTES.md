# v0.3.0-preview.1 — 벤토 그리드 Windows EXE

회계데이터 표준화 도구에 데스크톱 UI를 추가하고, 화면·서비스·핵심 처리·엑셀 입출력을 작은 모듈로 분리했습니다.

- 토스 UX 가이드를 참고한 벤토 그리드 작업 공간과 해요체 안내
- 파일 선택·드롭, 시트·헤더 행·원본 열 연결
- 계정 검색·미확정 필터, 후보와 추천 근거, 확인·거절·나중에 검토
- 원장·재무상태표 결과 미리보기와 검토 엑셀 저장, 결과 폴더 열기
- UI를 멈추지 않도록 파일 작업을 백그라운드로 분리
- Python 설치 없이 실행하는 Windows 64비트 휴대용 EXE 실행팩
- 오픈 라이선스 한글 글꼴·자체 아이콘과 라이선스 문서 포함

## 다운로드와 시작

`account-data-normalizer-0.3.0-preview.1-windows-x64.zip`을 모두 풀고 폴더 안 `AccountDataNormalizer.exe`를 실행하세요. `_internal` 폴더는 EXE와 함께 보관해야 합니다. Python·Codex 설치가 필요하지 않습니다.

## 검증 상태

사용자 요청에 따라 **업무 변환·회계 결과·GUI 업무 흐름의 기능 검증은 실행하지 않았습니다.** 초기 화면 렌더링과 EXE 초기화·번들 리소스 확인만 배포 준비 범위에서 확인합니다. 사용자 검증 대기 상태의 prerelease입니다.

현재 재무제표 범위는 BS입니다. 공식 XBRL GL 출력과 기존 감사 앱 직접 불러오기는 이번 릴리스에 포함하지 않습니다.
