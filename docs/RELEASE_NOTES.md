# v0.15.0-preview.1 — DSD 엑셀 연결·변경 검토·초안 반영

- `공시 검토` 메뉴에 DSD → 엑셀, DSD 버전 비교, HTML 검토보고서, 정산표 → DSD 화면을 추가했습니다. 파일 읽기와 변환은 백그라운드에서 처리합니다.
- DSD XML 표의 병합·원본 위치·단위와 공란/대시/0을 보존해 Excel로 추출합니다. 정밀도를 잃을 수 있는 숫자는 원문 텍스트로 남깁니다. 원본 SHA-256과 숨긴 대응 정보는 수정본을 같은 양식에 반영할 때 원본과 다시 검사합니다.
- 수정 전후 DSD의 숫자·문구·표 구조·본문 변경을 비교합니다. 표 삽입이나 내부 파일명 변경에 따른 불필요한 전체 변경을 줄이고 모호한 표·행 대응은 확인 필요로 남깁니다.
- 버전 비교와 기존 DSD·IXD 대사 결과를 검토 의견과 함께 외부 리소스 없는 HTML 한 파일로 저장합니다. 원본을 다시 확인하며 원본 XML·외부 링크를 실행하지 않습니다.
- 원본 DSD 양식에 추출 엑셀 수정본의 셀을 반영하거나 임의 정산표의 셀을 직접 연결해 새 초안을 만듭니다. 사용자가 회사·기간·단위·반영 값을 확인해야 합니다. 원본·이전 결과를 덮어쓰지 않고 출력 파일을 다시 읽어 변경 범위를 확인합니다.
- 기존 원장 표준화·Ollama 추천·사람 승인·공시 XML·업무파일 보안 기능을 유지합니다. 공식 FSS 바이너리·IFRS/DART 택사노미·로컬 모델 가중치는 배포하지 않습니다.

DSD 출력은 사용자가 선택한 원본 양식을 보존하는 **편집용 초안**입니다. 임의 XML을 공식 DSD로 포장하거나 XBRL 태깅·공식 전송파일·접수 성공으로 표시하지 않습니다. XML 표를 읽을 수 있는 DSD/XML/ZIP과 수식·매크로·외부 연결 없는 Excel 확정값 사본을 지원합니다. 복잡한 혼합 서식과 임의 행·열·병합 변경은 안전하게 반영할 수 없으면 거부합니다. 이번 버전에서는 공식 DART 편집기를 실행하지 않았으므로 편집기 열기·형식검사는 미확인입니다.

사용법과 지원 범위는 [DSD 작업 안내](DSD_WORKFLOW.md)를 참고하세요. 검증 수량·실행 결과는 릴리스의 `validation-summary.json`에 기록합니다. 검토자 이름은 로그인 인증이 아니며 업무 파일 암호화·Windows 코드서명은 미적용입니다.

- 다음 연도에 회사·개념·차원·단위·주석 구조를 재사용하고 새 당기 값은 공란, 이전 당기 값은 비교기간으로 보관
- 회사·기간·공시값·주석 변경과 연도 재사용에서 승인 해제, 택사노미 재확인. 공시 입력 초안 JSON을 기존 IFRS/DART 화면에서 검토·승인
- 공개 기능 설명과 공식 XBRL/OpenDART 자료로 자체 설계. 인벡터 내부 코드·계정·비공개 자료 사용 없음
- 기존 공식 DTR 주당이익 자료형 인식과 불러오기 XSD의 namespace 보존 수정 포함

매핑은 계정 사전·별칭·문자열 유사도·승인 이력 방식입니다. 로컬 LLM이나 외부 LLM API를 사용하지 않습니다. 대사에는 대응을 명시적으로 확인해야 하며 같은 숫자·비슷한 계정명으로 자동 승인하지 않습니다.

**확인 범위:** 자체 합성자료의 서비스·화면·EXE 검증 결과는 `validation-summary.json`에 기록합니다. DSD는 XML TABLE/TR/TD 계열 구조를 포함하는 파일만 읽으며 비XML 이진 형식은 지원하지 않습니다. 자유 서술 주석은 업무 메타데이터이고, XBRL에 포함할 서술은 별도 NOTE 팩트로 공식 개념·문맥을 지정해야 합니다. 이 앱은 DSD 자체를 다시 작성하는 편집기나 공식 IXD 생성기의 범용 대체품이 아닙니다.

별도 로컬 시험에서는 공식 작성기 본체로 합성자료의 제출용 IXD 생성 및 독립 기술검사 오류·경고 0건을 확인했습니다. 그 생성 연결과 공식 프로그램·택사노미·시험 IXD는 이 실행팩에 포함하지 않습니다. 이번 대사 기능은 로컬에서 사용자가 선택한 IXD를 읽습니다. 실제 DART 접수, 실사용 회사의 회계 적정성 및 전체 주석 완전성은 검증하지 않았습니다.

Windows 실행팩 ZIP을 모두 푼 뒤 `AccountDataNormalizer.exe`를 실행하세요. `_internal` 폴더를 함께 보관합니다. 자세한 순서는 `docs/DISCLOSURE_COMPARE.md`, `docs/DISCLOSURE_WORKSPACE.md`와 `docs/MANUAL_VALIDATION.md`를 참고하세요.
