# HTML 검토보고서와 정산표 → DSD 초안

## HTML 검토보고서

DSD 버전 비교 또는 DSD·IXD 대사 결과를 한 개의 HTML 파일로 저장합니다. 변경 전후 값, 표·행·열 위치, 비교 상태, 차이 설명, 원본 SHA-256과 검토 의견을 포함합니다. 전체 의견과 행별 의견은 단순 입력 기록이며 사용자 인증이나 전자서명이 아닙니다.

외부 글꼴·이미지·스크립트·라이브러리를 요청하지 않습니다. 원본 문구를 HTML 태그로 실행하지 않고 이스케이프하며, 출력하는 진단문·위치의 URL과 절대 경로는 생략합니다. 브라우저에서 인쇄할 수 있고, 공유할 때는 검토보고서에 실제 공시 숫자·서술이 담긴다는 점을 확인하세요.

화면에서 현재 비교의 원본 경로를 넘기면 저장 직전 원본 해시를 다시 검사합니다. API에서 경로를 생략하면 비교 당시 스냅샷만 저장하며 **저장 시 원본 미재확인**을 명시합니다. 보고서 JSON 안의 임의 경로를 열지 않습니다. 결과의 `pass`는 비교 범위 일치를 뜻하며 전체 공시의 완전성·회계 적정성·공식 검사·제출 승인을 뜻하지 않습니다.

```python
from xbrl_filing.dsd_reporting import export_dsd_review_html

export_dsd_review_html(
    comparison, '검토보고서.html',
    source_paths={'before': '수정전.dsd', 'after': '수정후.dsd'},
    reviewer='검토자 입력값', notes={'general': '전체 의견', '변경행ID': '행별 의견'},
)
```

DSD·IXD 결과는 `source_paths={'dsd': '원문.dsd', 'ixd': '제출후보.ixd'}`를 사용합니다. 10만 개 결과 행, 개별 표시값 1Mi자, UTF-8 HTML 128MiB 한도를 넘으면 전체 출력을 거부하며 결과를 조용히 생략하지 않습니다.

## 정산표 → DSD 초안

이 기능은 **사용자가 가진 기존 DSD/XML 템플릿의 셀 값을 수정**합니다. 새 공시서식을 추정하거나 일반 XML에 `.dsd` 확장자를 붙여 제출파일로 만들지 않습니다. 원장 분개·시산표를 자동으로 주석 전체에 배분하지 않으며 회사·기간·연결/별도·표시 단위를 추정하지 않습니다.

두 가지 입력 방식을 지원합니다.

1. **DSD에서 추출한 엑셀:** 같은 원본 DSD 템플릿을 선택합니다. 숨김 출처 시트의 파일 해시·전체 표·전체 셀·원문·원숫자·머리글·병합 구조를 원본과 대조한 뒤 원래 위치에 연결합니다. 엑셀에서 원문 표 셀 값만 편집하며 행·열·병합 구조를 유지해야 합니다. `변환안내`·`본문` 시트는 참고용이며 그 시트의 편집은 자동으로 DSD에 반영하지 않습니다. 빈값·대시·0은 다르게 처리합니다. 수정하지 않은 숫자는 원래 괄호 음수·천 단위 쉼표·백분율 표시를 보존합니다.
2. **일반 정산표:** 엑셀 시트·셀과 DSD의 대상 셀을 직접 선택하고 각 연결을 확인합니다. 이 연결은 두 원본 파일의 SHA-256에 묶습니다. 어느 원본이든 변경되면 다시 불러와 확인해야 합니다. 같은 대상 셀을 중복 연결하거나 병합 셀의 실제 값이 없는 위치를 연결할 수 없습니다.

표시 배율은 명시적으로 지정한 숫자에만 적용합니다. 예를 들어 엑셀 `200`에 `1000`을 지정하면 DSD 텍스트는 `200000`입니다. 텍스트의 `천원`이나 표 제목을 근거로 배율을 추정하지 않습니다. 추가 배율이 없는 활성 백분율 서식 숫자 `0.25`는 DSD `25%`로 기록합니다. 따옴표·역슬래시로 표시하는 `%` 문자에는 100배를 적용하지 않으며, 조건부·중복 백분율 서식은 표시값을 텍스트로 준비하도록 안내합니다. 셀 서식의 반올림·문자 장식·쉼표 배율을 재현하는 Excel 계산 엔진은 아닙니다. 날짜·논리값·오류값은 자동으로 공시 텍스트로 추정하지 않으며 확정된 문자열이나 숫자로 준비해야 합니다.

일반 정산표의 OOXML 숫자 원문은 이진 부동소수점으로 축약하지 않고 Decimal로 읽습니다. `1.000000000000000001` 같은 저장값을 그대로 유지하며, 검사 화면에서는 정수는 숫자, 소수는 정확한 문자열과 숫자 구분을 제공합니다. 유한한 200자리 숫자까지 지원하고, 매우 큰 지수나 중복 셀 좌표는 거부합니다. 엑셀이 저장하기 전에 이미 반올림한 값을 복원하는 기능은 아닙니다.

엑셀은 50MiB 이하의 값 전용 `.xlsx`이고 수식·외부 링크·매크로·임베디드 객체를 거부합니다. 지원 시트 범위는 10만 행·80열, 전체 값이 있는 셀 10만 개와 검사 범위 100만 셀 이내입니다. 수식을 계산하거나 외부 링크를 갱신하지 않습니다.

DSD ZIP의 구성요소 이름·순서·ZipInfo·압축 주석을 유지하고 수정이 있는 XML만 갱신합니다. 그 밖의 구성요소는 원본과 SHA-256을 대조합니다. 알 수 없는 XML 요소·속성과 단일 텍스트를 감싼 서식 태그는 유지합니다. 여러 서식 조각으로 나뉜 혼합 텍스트 셀은 임의로 합치지 않고 DART 편집기에서 수정하도록 안내합니다. 원본은 덮어쓰지 않으며 완성한 임시파일을 다시 읽어 전체 셀 값·위치·병합 구조를 확인한 뒤 새 파일로 저장합니다. 읽기 전후·저장 직전 파일 해시를 다시 확인하여 일반적인 동시 수정을 탐지합니다. 이 확인은 운영체제 파일 잠금이나 악성 프로세스의 순간 교체까지 방어하는 보안 경계는 아닙니다.

```python
from xbrl_filing.dsd_roundtrip import (
    inspect_workbook_cells, build_workbook_mapping, export_workbook_to_dsd,
)

# 일반 정산표는 화면에서 두 원본을 확인하고 셀 연결을 승인합니다.
envelope = build_workbook_mapping('원본.dsd', '정산표.xlsx', [
    {'sheet': '재무상태표', 'cell': 'C10',
     'dsdCellId': 'contents.xml#t1:r4:c2', 'confirmed': True, 'scale': '1'},
])
result = export_workbook_to_dsd('원본.dsd', '정산표.xlsx', '새초안.dsd', envelope)

# DSD에서 추출하고 구조를 유지한 엑셀은 원본 출처 전체 검증 후 연결합니다.
result = export_workbook_to_dsd('원본.dsd', '원본_추출.xlsx', '새초안.dsd')
```

일반 정산표 연결 형식은 `account-normalizer-dsd-workbook-mapping/1`, `sourceHashes: {template, workbook}`, `mappings` 목록입니다. 해시 없는 단순 목록은 출처가 바뀐 연결을 적용하지 않도록 거부합니다. 이력에 검토자 이름이 있더라도 신원 인증을 대신하지 않습니다.

## 공식 편집기 확인 범위

새로 저장한 파일은 앱의 안전한 XML/ZIP 판독기로 재검사한 **편집용 초안**입니다. 모든 DART 편집기의 독자적 이진형식이나 전체 DSD 작성 규격을 구현한 것은 아닙니다. XML 표가 없는 파일·지원 범위를 넘는 구조는 거부합니다. **공식 DART 편집기에서 열기·파일형식검사·전자공시 화면 미리보기는 이번 백그라운드 검증에서 실행하지 않았습니다.**

금감원 안내에서는 문서 작성·저장 후 파일형식검사, 전자공시 화면 미리보기, 전송파일 생성·전자서명과 접수를 별도 단계로 설명합니다. 앱이 저장한 DSD 초안을 최종 제출물이나 DART 접수 성공으로 표시하지 않습니다.

참고한 공개 1차자료:

- [금융감독원 DART 기업공시 길라잡이](https://dart.fss.or.kr/info/main.do?menu=510): 공식서식 작성, 파일형식검사, 미리보기와 전송파일 생성·제출 절차. 직접 열기는 HTTP 502였으며 공개 검색에 색인된 해당 공식 안내를 확인했습니다.
- [금융감독원 OpenDART 공시서류원본파일 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003): 원문 반환이 ZIP 바이너리이고 브라우저에서 XML 확장자로 저장될 수 있음을 확인했습니다. 원문 ZIP을 공식 편집기 DSD와 동일한 형식이라고 단정하지 않습니다.

인벡터의 소개 자료는 기능 요구 참고로만 사용했습니다. 외부 프로그램·비공개 코드·접수 계정은 사용하지 않았으며 OS 마우스·키보드나 공식 편집기를 조작하지 않습니다.
