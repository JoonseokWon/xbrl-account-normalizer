# 여러 회사 원장

10개 더미 회사의 XLSX 원장입니다. `새 파일 열기`로 하나씩 선택합니다. 원본에 확정 매핑표는 넣지 않았으므로 새 회사의 계정 검토 과정부터 확인할 수 있습니다.

계정별 정답·정의·회사·ERP는 `cases.json`, 별칭 추가 내역과 학습/평가 구분은 `learning-report.json`에 있습니다. 각 계정의 원본 코드와 행ID는 텍스트이며 앞자리 0을 유지합니다. 모든 금액은 KRW 원입니다.

학습은 6개 회사의 명확한 표현에만 사용합니다. 나머지 4개 회사는 조직 표기 변형을 평가합니다. 실제 회사 자료·실제 승인 서명은 포함하지 않았습니다.
