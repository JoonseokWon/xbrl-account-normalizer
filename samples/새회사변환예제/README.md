# 새 회사 원장 변환 예제

노바부품의 원장 변환용 테스트데이터입니다. 모든 거래·금액·시산표·통제·매핑은 시험자료이며 실제 독립 추출 증거나 실제 사용자 승인이 아닙니다.

기간은 2026-01-01~2026-01-31, 회사코드는 NOVA_DEMO, 원천시스템은 ERP-DEMO-B입니다. 14개 전표·28개 행·원본 계정 8개를 사용합니다. 두 은행 원본 계정은 표준 계정 A1102로 함께 연결되므로 표준 계정은 7개입니다.

1. `01_노바부품_원본원장.xlsx`: 첫 `분개장` 시트에서 전표별 차변 계정·금액과 대변 계정·금액을 나란히 봅니다. `GL_Data`는 변환에 쓰는 28행 원본으로 회사·일자·전표·행·계정코드·계정명·차변·대변·적요·작성자가 있습니다. 계정코드와 행ID는 텍스트입니다.
2. `02_노바부품_시산표_통제자료.xlsx`: 별도로 기재한 시험 기대값과 보조 5개 시트입니다. 통제값을 변환 원장으로 덮어 맞추지 않습니다. 감사조정은 없는 것으로 명시해 헤더만 두었습니다.
3. `예제_열연결.json`, `예제_입력프로필.json`: GL_Data의 원본 열을 표준 입력에 연결합니다.
4. `예제_계정연결.json`: 이 합성 시나리오의 명시적인 계정 연결 설정입니다. 추천 점수로 자동 승인한 기록이 아닙니다.
5. `시나리오.json`: 행·계정 수, 차변·대변 각각 26,700,000원의 기대값입니다.

GUI에서는 새 파일 열기 → 원본 원장 선택 → 회사/시스템 확인 → GL_Data와 원본 열 연결 → 계정 검토를 진행합니다. 연결 후 변환 결과의 통합감사 입력 저장에서 보조파일을 선택합니다.

`분개장`은 읽기용으로, 변환할 때 중복 합산하지 않습니다. 계좌 이체는 차변 신한은행 2,000,000원 / 대변 국민은행 2,000,000원이며, 원가 처리는 차변 매출원가 / 대변 재고자산입니다. 차대변은 계정·금액 열로 구분하고 적요도 같은 분개를 표시합니다. 두 은행은 서로 다른 원본 계정코드를 유지합니다.

전체 자동 재현은 프로젝트 루트에서 `python tools/run_audit_demo.py --audit-suite "통합감사 소스 폴더" --audit-python "해당 의존성이 설치된 python.exe"`로 실행합니다. 새 출력 폴더와 별도의 더미 감사업무를 생성하며 기존 업무는 수정하지 않습니다.
