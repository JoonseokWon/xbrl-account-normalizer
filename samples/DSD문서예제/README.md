# DSD 문서 작업 예제

모든 값·문구·ZIP은 이 프로그램의 검증을 위해 직접 만든 자료입니다. 공식 DART 서식이나 제출용 파일이 아니며 접수에 사용하지 마세요.

1. 공시 검토 → DSD → 엑셀에서 `검토용_원본.dsd`를 새 이름의 Excel로 저장합니다. 표별 병합·단위·공란·대시·백분율과 `본문` 참고 시트를 확인합니다.
2. `표_추출.xlsx`는 추출 결과입니다. `수정한_표.xlsx`는 현금 주석의 국민은행 당기/전기 값 두 개를 1,350원/950원으로 바꾼 사본입니다.
3. 정산표 → DSD에서 `검토용_원본.dsd`와 `수정한_표.xlsx`를 선택하고 첫 모드로 읽습니다. 값과 단위를 확인한 뒤 새 이름으로 저장합니다. `수정_초안.dsd`와 같은 변경 범위가 나와야 합니다.
4. DSD 버전 비교에서 원본과 수정 초안을 비교하면 숫자 변경 2건이 나옵니다. 3번 HTML 검토보고서 탭에서 의견을 입력하고 새 파일로 저장합니다. `변경_검토보고서.html`은 이 결과의 읽기 전용 사본입니다.
5. 다른 정산표를 시험하려면 `다른정산표.xlsx`를 두 번째 모드로 읽습니다. `기말잔액!B2`는 국민은행 당기 1,200원 셀, `B3`는 신한은행 당기 800원 셀, `B4`는 합계 2,000원 셀에 각각 직접 연결합니다. 배율은 1입니다. 값을 확인한 뒤 새 파일로 저장하면 `정산표_반영초안.dsd`와 같이 세 값만 1,350원/850원/2,200원으로 바뀝니다.

합계를 자동 계산하거나 회계 판단을 승인한 예제가 아닙니다. 같은 이름의 원본·결과를 덮어쓰지 않습니다. 본문 시트 편집은 DSD에 자동 반영되지 않습니다. 공식 형식검사·열기·접수는 이 예제의 확인 범위가 아닙니다.
