# 공시 검토 입력 예제

이 폴더는 자체 합성자료입니다. 실제 회사 자료와 공식 작성기·택사노미를 포함하지 않습니다.

## DSD·IXD 숫자 대사

`공시 검토 → DSD·IXD 숫자 대사`에서 `.dsd`와 `.ixd`를 선택하고 셀·항목을 읽습니다. `대응표 열기`에서 `합성_대응표.json`을 선택한 뒤 대사합니다.

- 당기 1,234 × 1,000 = 1,234,000
- 전기 1,100 × 1,000 = 1,100,000
- 괄호 음수 (20) × 1,000 = -20,000

이 IXD는 읽기·대사 시험용으로 직접 만든 최소 컨테이너입니다. **공식 작성기가 생성한 IXD나 제출 가능한 공시 파일이 아닙니다. 제출하지 마세요.** 구조 인식과 공식 기술검사·생성·접수는 별도입니다.

## 주석 편집·변경 이력·다음 연도

`공시 검토 → 주석·변경 이력·다음 연도 업무`에서 `주석 업무 열기`로 `공시검토_입력예제.acdisclosure`를 엽니다. 또는 `공시 입력 가져오기`에서 `공시입력_검토초안.json`을 선택합니다. 새 회사는 `새 업무`를 누르고 회사와 기간을 직접 입력하세요.

주석과 팩트를 수정하고 변경 이력을 확인한 다음 새 이름으로 저장합니다. 다음 연도 업무 만들기는 먼저 현재 업무를 저장해야 합니다. 이전 당기 금액을 비교기간에 보존하고 새 당기는 공란으로 시작하며, 공식 택사노미와 개별 항목의 재검토·승인이 필요합니다. 주석 자유 서술은 업무 메타데이터이고 공식 XML에 자동 삽입되지 않습니다.
